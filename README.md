# CoPill legal

Public pages of the [CoPill](https://github.com/ChespiG/CoPill) app, served with GitHub Pages:

- Privacy policy (es): https://chespig.github.io/copill-legal/
- Privacy policy (en): https://chespig.github.io/copill-legal/en/
- Account deletion: `#borrar-cuenta` / `#delete-account` on those pages (Google Play asks for this link).

The app links these URLs (`legal_privacy_policy_url` in its strings). Keep both languages in sync and update the effective date on every change.
